# 今天也在破案！


独立完成的轻喜剧推理游戏原型。玩家在甜品店场景中切换王侦探、小李与旺财，通过探索、差异化调查、线索收集和推理验证，解决“布丁失踪案”。


## 项目主页


**[查看在线作品主页](https://chcccchi.github.io/today-also-solving-cases/)**  
包含玩法演示视频、核心界面截图与项目作品集。


## 试玩下载


**[下载 Windows 试玩版 v1.2](https://github.com/chcccchi/today-also-solving-cases/releases/tag/v1.2)**  
进入发布页后，在 `Assets` 中下载 `today-also-solving-cases_Windows_v1.2.zip`；解压后双击 `今天也在破案！试玩版.exe` 启动。首次启动会从开场教学进入游戏。


## 项目概况


- **开发引擎：** Godot 4
- **项目类型：** 单人轻剧情推理解谜
- **可体验内容：** 序章与第一章《布丁失踪案》
- **个人职责：** 玩法策划、系统设计、关卡设计、菜单与交互设计、部分开发
- **开发周期：** 约 2 周完成当前可体验版本
