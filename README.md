# 今天也在破案 项目作品主页

这是用于 GitHub Pages 的静态作品集主页，包含玩法演示、项目截图和作品集 PDF。

## 发布步骤

1. 在 GitHub 新建一个公开仓库，建议仓库名为 `today-also-solving-cases`。
2. 上传本目录内的所有文件和 `assets` 文件夹。
3. 仓库进入 **Settings → Pages**，在 **Build and deployment** 里选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/(root)`，保存。
4. 等待 GitHub 生成站点地址。使用建议仓库名时，正式地址为：`https://chcccchi.github.io/today-also-solving-cases/`。

## 投递时使用

- 简历作品链接：GitHub Pages 首页地址
- 试玩包：后续放在仓库的 Releases 中，再把下载链接补到首页
- 公开项目不上传账号密码、私密素材、可商用授权不明的资源和完整开发缓存
