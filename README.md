# 今天也在破案！

独立完成的轻喜剧推理游戏原型。玩家在甜品店场景中切换王侦探、小李与旺财，通过探索、差异化调查、线索收集和推理验证，解决“布丁失踪案”。

## 项目主页

**[查看在线作品主页](https://chcccchi.github.io/today-also-solving-cases/)**  
包含玩法演示视频、核心界面截图与项目作品集。

## 项目概况

- **开发引擎：** Godot 4
- **项目类型：** 单人轻剧情推理解谜
- **可体验内容：** 序章与第一章《布丁失踪案》
- **个人职责：** 玩法策划、系统设计、关卡设计、菜单与交互设计、部分开发
- **开发周期：** 约 2 周完成当前可体验版本

## 核心设计

### 三角色差异化调查

| 角色 | 调查特点 | 体验目的 |
| --- | --- | --- |
| 王侦探 | 逻辑推理与案件判断 | 组织推理链，推动结案 |
| 小李 | 现场观察、时间分析、物证判断 | 发现环境细节与关键物证 |
| 旺财 | 气味追踪、动物交流 | 提供普通角色无法获得的信息 |

同一地点会因角色不同而提供不同反馈，让调查从“清空点位”变成“选择适合的角色尝试”。

### 探索与引导

- 主线关键线索只展示数量，避免提前泄露内容。
- 玩家可主动使用限时提示，不强制降低探索难度。
- 通过隐藏任务、重复调查、彩蛋对话与角色专属玩法提供非主线回报。
- 旺财拥有气味追踪小游戏，以路线重合度和实时进度反馈完成判定。

### 推理闭环

探索场景 → 切换角色调查 → 收集线索 → 组合证据 → 最终问答 → 结案后剧情收束。

最终推理选项会随机排列，避免玩家仅凭记忆重复作答。

## 迭代记录

- 将固定的简单 / 困难模式调整为玩家主动开启提示，保留探索自由度。
- 为气味追踪补充实时进度显示，降低玩法目标不清晰的问题。
- 将三角色同时移动改为单角色显示、自由切换，减少遮挡与移动拖沓。

## 本地运行

1. 使用 Godot 4 导入本目录的 `project.godot`。
2. 运行项目主场景即可开始体验。

## 后续计划

后续案件计划加入王侦探的“回溯”能力：玩家在固定时间节点间选择回看并修正判断，以新的线索重新观察已被破坏或遗漏的细节。
